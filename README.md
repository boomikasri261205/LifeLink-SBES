# 🩸 LifeLink SBES

LifeLink SBES (Smart Blood Emergency System) is a web application developed to help people quickly find hospitals and blood donors during medical emergencies.

## 📌 Project Overview

This project provides a centralized platform where users can:

- Register as blood donors
- Request blood during emergencies
- Search hospitals district-wise
- View government and private hospitals
- Access hospital contact information
- Store and manage data using Firebase Firestore

## ✨ Features

- 🩸 Blood Donor Registration
- 🚑 Emergency Blood Request
- 🏥 District-wise Hospital Database
- 📍 Hospital Search
- ☁️ Firebase Firestore Integration
- 📱 Responsive Design
- 🔍 Duplicate Hospital Check During Upload

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Firebase Firestore
- Firebase Authentication

## 🎯 Objective

The main objective of LifeLink SBES is to reduce the time required to find hospitals and blood donors during emergency situations by providing a reliable and organized platform.
